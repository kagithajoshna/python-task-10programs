Python Test Cases: List, Matrix, and Tuple Analysis
This document describes Python programs for practical problems using nested lists, matrices, and tuples. The test cases focus on data representation, validation, calculations, comparisons, and reporting.
Test Cases Included
**41. Nested List Classroom Occupancy Analysis**
Represent classrooms and seating positions using nested lists.
•	Allocate students to available seats.
•	Preserve reserved seats.
•	Detect duplicate student assignments.
•	Calculate vacant seating capacity.
**42. Student Marks Matrix Analysis**
Analyze a matrix of student marks across subjects.
•	Calculate row-wise statistics for each student.
•	Calculate column-wise statistics for each subject.
•	Identify top-performing students.
•	Detect subjects with a low average score.
**43. Multi-Branch Sales Matrix Comparison**
Store product sales across branches and days using nested lists.
•	Calculate total sales for each product.
•	Compare sales performance across branches.
•	Identify the best-performing product in each branch.
**44. Hospital Ward Occupancy Monitoring**
Analyze bed occupancy counts by ward and day using a nested list.
•	Calculate ward utilization percentages.
•	Detect capacity violations.
•	Identify peak-demand periods.
**45. Weekly Electricity Consumption Matrix**
Process appliance-wise electricity readings for seven days.
•	Calculate daily electricity consumption.
•	Calculate total consumption for each appliance.
•	Identify consumption that exceeds specified limits.
**46. Inventory Matrix Reconciliation**
Compare product quantities across warehouses using nested lists.
•	Identify stock shortages and surpluses.
•	Compare available quantities with target stock levels.
•	Calculate transfers required to meet stock targets.
**47. Sports Tournament Ranking System**
Store match results and team scores.
•	Calculate total points for each team.
•	Compute tie-break values.
•	Rank teams according to a specified competition policy.
**48. Tuple-Based Employee Shift Conflict Detection**
Represent employee shifts as tuples.
•	Compare shift time intervals.
•	Detect overlapping assignments.
•	Identify employees with conflicting schedules.
**49. Tuple-Based Product Catalogue Audit**
Store product identifiers, prices, and stock quantities in tuples.
•	Detect invalid product records.
•	Calculate total inventory value.
•	Identify products requiring replenishment.
**50. Tuple-Based Route Distance Analysis**
Store geographical coordinates as tuples.
•	Calculate distances between successive points using a supplied formula.
•	Identify the longest route segment.
**Concepts Practiced**
•	Python lists and nested lists
•	Matrices and row-wise/column-wise processing
•	Tuples and tuple unpacking
•	Loops and conditional statements
•	Data validation and duplicate detection
•	Basic statistical calculations
•	Searching, comparison, and ranking
•	Inventory and capacity calculations
•	Distance calculations
•	Input handling and output reporting

•	No external libraries are required for the basic implementations.
**How to Run**
1.	Clone or download the repository.
2.	Open the project folder in VS Code or a terminal.
3.	Open the terminal in the folder containing the Python program.
4.	Run the required test case using the command below.
**python filename.py**
Replace filename.py with the name of the Python file you want to execute.
